# Limpieza-PDF
# Apto para mejoras de escalabilidad

# Pequeño programa que sirve para limpiar pdf y convertirlos a markdown

#Tienes dos vías para usarlo: 
#1. 
Abres la terminal en la carpeta donde tengas este proyecto
Corres python limpiar_pdf.py  (asegúrate de dejar un espacio al final).
Vas a la carpeta donde tienes tu otro PDF, le das un clic y lo arrastras hacia la ventana de la terminal.
Presionas Enter. El resultado .md aparecerá mágicamente en la otra carpeta que tiene al PDF original.

#2. 
Abres la terminal en la nueva carpeta (donde está el PDF a procesar).
Escribes la ruta completa del script y el nombre de tu PDF, ejemplo: python "C:\Users\Usuario1\Descargas\Conversion-PDF\limpiar_pdf.py" "archivo.pdf"
Presionas Enter y el archivo .md aparecerá allí mismo.
